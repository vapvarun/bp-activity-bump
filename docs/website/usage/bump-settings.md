# Choose what bumps an activity

**Included in Free**

Go to **WB Plugins > Activity Bump > General** and pick one option under **Bump On**.

| Option | What it does |
|---|---|
| Like/Favorite | An activity moves to the top when a member likes it. |
| New Comment | An activity moves to the top when a member comments or replies. |
| Both | Either action moves it. This is the default. |

Click **Save Changes**. A "Settings saved." message confirms the change and it applies immediately.

## What members see

The activity appears at the top of the stream. Its time stays the original post time, for example "3 days ago", so members can tell an old post that is being discussed from a new post.

## What does not change

- Who can see an activity. Bumping only changes the order, never the privacy of a post.
- Comments inside a thread keep their own dates.
