# Overview

**Included in Free**

BuddyPress Activity Bump moves an activity to the top of the stream when someone comments on it or likes it. A busy conversation stays visible instead of sinking under newer posts.

- A comment or reply on an activity bumps it.
- A like (favorite) on an activity bumps it.
- The activity keeps its original post time, so members still see when it was first written.
- It works on the sitewide stream, group streams, member profiles and the single activity page.
- Replies and likes on a comment do not move anything: only the top-level post is bumped.

## What the plugin needs

BuddyPress with the Activity component switched on.
