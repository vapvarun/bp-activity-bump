# Installation

**Included in Free**

1. Download the plugin zip from the GitHub releases page of the plugin.
2. In WordPress go to **Plugins > Add New > Upload Plugin**, choose the zip and click **Install Now**.
3. Click **Activate**. You are taken to the plugin settings.

Bumping works straight away with the default setting (Both). Nothing else needs to be configured.

Updates are published as new GitHub releases. Install a new zip over the old one to update.
