# Frequently asked questions

## Does bumping change who can see an activity?

No. Group and private activities stay visible only to the people who could see them before. Only the order changes.

## Why does a bumped activity still show its old time?

That is by design. The original post time is kept so members can see how old the discussion is.

## Does liking a comment bump the post?

No. Only comments and likes on the post itself bump it.

## Does it work on sites with a caching plugin?

Yes. Stream results are refreshed on every bump, including on sites that use Redis or Memcached object caching.
