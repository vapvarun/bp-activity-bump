# What's New in 1.2.5

Version 1.2.5 makes bumping reliable on sites with object caching and tidies the settings page. It is a safe update with no settings to change.

- The stream reorders right after a bump on sites with Redis or Memcached.
- Liking a comment no longer changes the comment's date.
- The "Settings saved." message is visible again.
- The plugin stays active, with a notice, if BuddyPress is switched off for an update.
- The plugin needs PHP 8.1 or newer and no longer bundles an update checker: updates come from GitHub releases.
